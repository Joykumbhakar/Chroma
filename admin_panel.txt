1. EXECUTIVE SYSTEM OVERVIEW & ARCHITECTURE
====================================================================================================
ChromaStudio (also branded as Oscellion) is a high-performance creative mobile studio and creator 
social ecosystem built on Android (Kotlin, Jetpack Compose, Material 3, Samsung One UI / Apple Glass 
Design System) connected to a multi-backend cloud architecture:
1. Google Cloud Firebase / Firestore:
   - Primary NoSQL real-time document database.
   - Firebase Authentication (Google OAuth, Apple OAuth, Email/Password, Custom handle logins).
   - Firebase Cloud Messaging (FCM) for low-latency background notifications.
2. Supabase Cloud (PostgreSQL, Storage, Realtime):
   - Media Storage for avatars, banners, post media, and encrypted chat attachments.
   - Realtime websocket subscriptions for presence and telemetry.
3. Cloudinary CDN:
   - High-throughput video transcoding, poster frame extraction, and CDN optimization for Flash reels.
4. Google Gemini GenAI API:
   - Creative AI generative features, prompt expansion, smart captions, and automated content moderation.

The purpose of the Next.js Founder Admin Panel is to provide a single, omniscient web dashboard 
allowing the founder and company operators to:
- Monitor user growth, DAU/MAU, creator retention, and storage consumption in real time.
- Manage user profiles, verify creator accounts with badges, reset compromised sessions, and ban bad actors.
- Review flagged content (posts, reels, stories, comments, chat reports) in a triage queue.
- Broadcast system announcements and push notifications to segmented user demographics.
- Audit the health of cloud storage buckets and prune orphaned media assets.
- Configure feature flags, minimum app version requirements, and platform operational modes.

2.2. Collection: `users`
----------------------------------------------------------------------------------------------------
Path: `users/{uid}`
Document ID: Firebase Authentication UID string (e.g. "aB3dE8fK...")
Purpose: Stores comprehensive user creator profile, account state, badges, privacy settings.

Fields:
- `uid` (string, required): Firebase Auth UID.
- `username` (string, required): Clean lowercase unique handle (3-30 chars, a-z, 0-9, _).
- `displayName` (string, required): Public display name (e.g. "Elena Rostova").
- `email` (string, required): Primary verified email or OAuth email.
- `customEmail` (string, required): Internal handle email format: `{username}@oscellion.com`.
- `googleId` (string, optional): Associated Google OAuth ID.
- `bio` (string, optional): Public profile description (max 500 chars).
- `avatarUrl` (string, optional): HTTPS URL to profile image (Supabase / Cloudinary).
- `bannerUrl` (string, optional): HTTPS URL to profile cover banner.
- `bannerWorkId` (string, optional): ID of a community_work used as profile banner.
- `dob` (number, optional): Date of birth in UTC epoch milliseconds. Enforced 13+.
- `dateOfBirth` (any, optional): Legacy or alternate timestamp format for DOB.
- `gender` (string, default: "Private"): "Male" | "Female" | "Non-binary" | "Private".
- `role` (string, default: "Creator"): "Creator" | "Admin" | "Moderator" | "VIP".
- `verified` (boolean, default: false): True grants the official blue verified badge.
- `online` (boolean, default: false): Live presence indicator.
- `lastSeen` (number, optional): Epoch milliseconds timestamp of last active heartbeat.
- `location` (string, optional): General city/region display.
- `officeLocation` (string, optional): Professional office location.
- `homeLocation` (string, optional): Personal hometown.
- `countryLocation` (string, optional): ISO or full country name.
- `showLocation` (boolean, default: false): Visibility toggle for public location.
- `socialLinks` (map<string, string>): Map of platform key to URL (e.g., {"instagram": "...", "x": "..."}).
- `followersCount` (number, default: 0): Denormalized total followers count.
- `followingCount` (number, default: 0): Denormalized total following count.
- `interests` (array<string>): Array of chosen studio domains (e.g., ["Color Grading", "Motion Graphics"]).
- `statusEmoji` (string, optional): Single emoji status (e.g., "🎨").
- `statusText` (string, optional): Short status message (e.g., "Grading LUTs").
- `agreedToTermsAt` (number, optional): Epoch milliseconds when terms were accepted.
- `createdAt` (number / timestamp): Account creation timestamp.
- `isOnboarded` (boolean, default: true): Whether onboarding wizard was completed.
- `publicKey` (string, optional): Base64 encoded RSA-2048 public key for E2EE chats.
- `isPrivateAccount` (boolean, default: false): If true, requires follow requests to view posts.
- `allowTagging` (boolean, default: true): Whether others can tag/mention this user.
- `showOnlineStatus` (boolean, default: true): Whether online status dot is visible to others.
- `pushNotificationsEnabled` (boolean, default: true): Master push notification toggle.
- `emailNotificationsEnabled` (boolean, default: true): Email updates toggle.
- `quietModeEnabled` (boolean, default: false): Do not disturb / silent mode toggle.
- `unrecognizedLoginsEnabled` (boolean, default: false): Security alert on unknown device login.
- `contentTags` (array<string>): Creator tags applied to user's profile.
- `dataVisibility` (map<string, string>): Granular privacy settings.
- `onlyFriends` (array<string>): UIDs of close friends allowed in restricted stories.
- `fcmToken` (string, optional): Active device FCM registration token.
- `blockedUsers` (array<string>): UIDs blocked by this user.
- `isBanned` (boolean, default: false, ADMIN-MANAGED): If true, user is locked out.
- `banReason` (string, optional, ADMIN-MANAGED): Administrative explanation for ban.
- `bannedAt` (number, optional, ADMIN-MANAGED): Timestamp when ban was enacted.

2.6. Subcollection: `users/{uid}/highlights`
----------------------------------------------------------------------------------------------------
Path: `users/{uid}/highlights/{highlightId}`
Document ID: `highlightId` (UUID string)
Purpose: Permanent Instagram-style Story Highlights showcased in circular profile bubbles beneath the user bio.
Architecture Note:
- Highlights decouple story presentation from the 24-hour expiration rule.
- When an expired story is added to a Highlight, its `isHighlight` flag is set to true and its ID is added to `storyIds`.
- Expired stories inside highlights remain viewable indefinitely within the highlight modal but DO NOT reappear in the live 24-hour Stories section of the feed.
Fields:
- `id` (string): Unique highlight ID.
- `title` (string): Title label shown below the bubble (e.g. "Studio", "VFX Reels", "Vlog").
- `coverUrl` (string): HTTPS URL of the circular cover image (defaults to first story media or custom selected frame).
- `storyIds` (array<string>): Ordered array of Story document IDs preserved in this highlight.
- `createdAt` (number): Epoch milliseconds when the highlight was created.
- `updatedAt` (number): Epoch milliseconds when the highlight was last modified.

2.12. Collection: `flash_comments`
----------------------------------------------------------------------------------------------------
Path: `flash_comments/{commentId}`
Mirrors: 
- `community_works/{workId}/comments/{commentId}` (for community posts & masterworks)
- `flash_videos/{flashId}/comments/{commentId}` (for short-form video reels)
Document ID: `commentId` (UUID string)
Purpose: Authoritative real-time collection for threaded discussions, interactive polls, voice notes, media attachments, spoiler blocks, and creator badges.

Core Fields:
- `id` (string): Unique comment identifier (UUID v4).
- `videoId` (string): Associated post or flash video ID (matches `workId` in `community_works` or `flashId` in `flash_videos`).
- `userId` (string): Author's Firebase UID.
- `username` (string): Author's unique handle (e.g. "joykumbhakar").
- `displayName` (string): Author's profile display name.
- `avatarUrl` (string): URL to author's profile avatar.
- `verified` (boolean, default: false): Blue checkmark badge status.
- `text` (string): Comment text content supporting Markdown (bold `**text**`, italic `*text*`, code spans, timestamps `0:42`, and tap-to-reveal spoilers `||spoiler||`).
- `timestamp` (number): Epoch milliseconds when created.
- `likesCount` (number, default: 0): Aggregated total of likes.
- `likedBy` (array<string>): Array of user UIDs who liked this comment.
- `dislikedBy` (array<string>): Array of user UIDs who disliked this comment.
- `reactions` (map<string, array<string>>, optional): Quick emoji reactions map (e.g. `{"❤️": ["uid1"], "🔥": ["uid2"], "💯": ["uid3"]}`).
- `reactionCounts` (map<string, number>, optional): Counts per emoji reaction.
- `isPinned` (boolean, default: false): Pinned status; displays at top of the thread with a cyan pin pill.
- `isCreatorHearted` (boolean, default: false): Creator heart badge; displays author avatar overlay and red heart badge.
- `replyToCommentId` (string, optional): null for root comments; points to parent root comment ID for threaded replies.
- `replyToUsername` (string, optional): Tagged parent user's handle for `@mention` prefixing.
- `replyCount` (number, default: 0): Direct nested child reply counter.
- `replyFlashVideoUrl` (string, optional): HTTPS URL to a video response reel.

Interactive & Rich Media Extensions:
- `poll` (map, optional): Interactive in-comment poll data:
  * `id` (string): Unique poll ID.
  * `question` (string): Poll prompt text.
  * `options` (array<map>): List of options, each containing:
    - `id` (string): Option ID ("opt-1", "opt-2", etc.).
    - `text` (string): Option title.
    - `votesCount` (number): Number of votes cast.
    - `voterIds` (array<string>): Array of user UIDs who voted for this option.
  * `totalVotes` (number): Total sum of votes cast across all options.
  * `userVotedOptionId` (string, optional): Current authenticated user's selected option.
- `voiceNote` (map, optional): In-line voice message attachment:
  * `audioUrl` (string): HTTPS URL to the recorded voice note audio file (AAC/M4A).
  * `durationMs` (number): Audio duration in milliseconds.
  * `waveformAmplitudes` (array<number>): 20-50 normalized amplitude points (0.0 to 1.0) for live scrubbable waveform rendering.
- `media` (map, optional): Attached image, sticker, or GIF:
  * `type` (string: "image" | "video" | "gif"): Media category.
  * `url` (string): HTTPS media URL.
  * `aspectRatio` (number): Media aspect ratio (width / height).
  * `thumbnailUrl` (string, optional): Video/GIF preview thumbnail.
- `edited` (boolean, default: false): Indicates if the author edited their comment inline.
- `editedAt` (number, optional): Epoch timestamp of the last edit.
- `translation` (map, optional): Cached inline translation:
  * `translatedText` (string): Translated text content.
  * `targetLanguage` (string): Target ISO language code (e.g. "en", "es").
  * `detectedSourceLanguage` (string): Source detected ISO language code.
- `isSpam` (boolean, default: false, ADMIN-MANAGED): Content flagged by automated AI moderation or admin action.

4.3. Role-Based Access Control (RBAC) Matrix
--------------------------------------------
Implement custom claims on Firebase Auth (`adminRole`) or manage in `admin_users` collection:
- `FOUNDER_SUPERADMIN`: Full read/write/delete access across all 12 modules, financial metrics, 
  permanent user deletion, and direct database execution.
- `MODERATOR`: Access to Moderation Queue, Posts, Flash, Comments, and Stories. Can take down content, 
  issue user warnings, and enact 24h suspensions. Cannot permanently delete users.
- `SUPPORT_AGENT`: Access to User Management, Device Tokens, and Chat Metadata. Can trigger password 
  resets and view user account status. Cannot delete content or view admin logs.
- `CONTENT_CURATOR`: Access to Community Works, Featured Carousels, and Broadcast Notifications. 
  Can feature posts and create announcements.

```typescript
/**
 * Forcibly reassign a user's @username with atomic reservation index update.
 */
export async function overrideUsernameAction(
  uid: string,
  newUsername: string,
  reserveOldHandle: boolean,
  adminEmail: string
) {
  const cleanUsername = newUsername.toLowerCase().trim().replace(/^@/, '');
  if (!/^[a-zA-Z0-9_]{3,30}$/.test(cleanUsername)) {
    throw new Error('Username must be 3-30 alphanumeric characters or underscores.');
  }

  const userRef = adminDb.collection('users').doc(uid);
  const newUsernameRef = adminDb.collection('usernames').doc(cleanUsername);

  await adminDb.runTransaction(async (transaction) => {
    const userDoc = await transaction.get(userRef);
    if (!userDoc.exists) throw new Error('User does not exist.');

    const oldUsername = (userDoc.data()?.username || '').toLowerCase();
    const newUsernameDoc = await transaction.get(newUsernameRef);

    if (newUsernameDoc.exists && newUsernameDoc.data()?.uid !== uid) {
      throw new Error(`Username @${cleanUsername} is already reserved.`);
    }

    // 1. Claim new handle
    transaction.set(newUsernameRef, { uid, claimedAt: Date.now() });

    // 2. Release or reserve old handle
    if (oldUsername && oldUsername !== cleanUsername) {
      const oldUsernameRef = adminDb.collection('usernames').doc(oldUsername);
      if (reserveOldHandle) {
        transaction.set(oldUsernameRef, { reservedByAdmin: true, previousUid: uid, reservedAt: Date.now() });
      } else {
        transaction.delete(oldUsernameRef);
      }
    }

    // 3. Update user profile
    transaction.update(userRef, { username: cleanUsername });
  });

  await logAdminAction(adminEmail, 'OVERRIDE_USERNAME', uid, { newUsername: cleanUsername, reserveOldHandle }, 'user');
  revalidatePath(`/admin/users/${uid}`);
  revalidatePath('/admin/users');
  return { success: true };
}
```

```typescript
  const batch = adminDb.batch();
  let deletedCount = 0;

  snap.forEach((doc) => {

      matches = false;
    }

    if (matches) {
      batch.delete(doc.ref);
      deletedCount++;
    }
  });

  if (deletedCount > 0) {
    await batch.commit();
  }

  await logAdminAction(adminEmail, 'BULK_SPAM_PURGE', 'COMMENTS', { deletedCount, criteria }, 'comment');
  revalidatePath('/admin/comments');
  return { success: true, deletedCount };
}
```

```typescript
'use server';

import { adminDb } from '@/lib/firebaseAdmin';
import { logAdminAction } from '@/lib/auditLogger';
import { banUser } from './users';
import { revalidatePath } from 'next/cache';

export async function resolveReport(
  reportId: string,
  action: 'none' | 'warned' | 'content_removed' | 'suspended_24h' | 'banned_permanent',
  adminEmail: string
) {
  const reportRef = adminDb.collection('reports').doc(reportId);
  const reportSnap = await reportRef.get();
  if (!reportSnap.exists) throw new Error('Report not found');

  const report = reportSnap.data()!;

  // 1. Execute resolution action
  if (action === 'content_removed') {
    if (report.targetType === 'post') {
      await adminDb.collection('community_works').doc(report.targetId).update({
        isTakedown: true,
        takedownReason: `Violated terms: ${report.reason}`,
      });
    } else if (report.targetType === 'flash') {
      await adminDb.collection('flash_videos').doc(report.targetId).update({
        isTakedown: true,
        takedownReason: `Violated terms: ${report.reason}`,
      });
    } else if (report.targetType === 'comment') {
      await adminDb.collection('flash_comments').doc(report.targetId).delete();
    }
  } else if (action === 'warned') {
    // Send high-priority system warning notification
    await adminDb.collection('users').doc(report.targetAuthorId).collection('notifications').add({
      type: 'SYSTEM_WARNING',
      title: 'Community Guidelines Warning',
      body: `Your content was flagged for ${report.reason}. Repeated violations will result in account suspension.`,
      targetId: report.targetId,
      timestamp: Date.now(),
      isRead: false,
    });
  } else if (action === 'suspended_24h') {
    await adminDb.collection('users').doc(report.targetAuthorId).update({
      timeoutExpiresAt: Date.now() + 86400000,
      timeoutReason: `Suspended for 24h due to report: ${report.reason}`,
    });
  } else if (action === 'banned_permanent') {
    await banUser(report.targetAuthorId, `Banned via Report: ${report.reason}`, adminEmail);
  }

  // 2. Update report state
  await reportRef.update({
    status: 'resolved',
    resolutionAction: action,
    resolvedBy: adminEmail,
    resolvedAt: Date.now(),
  });

  await logAdminAction(adminEmail, 'RESOLVE_REPORT', reportId, { action, targetId: report.targetId }, 'moderation');
  revalidatePath('/admin/moderation');
  return { success: true };
}
```

```typescript
'use server';

import { adminDb, adminMessaging } from '@/lib/firebaseAdmin';
import { logAdminAction } from '@/lib/auditLogger';
import { revalidatePath } from 'next/cache';

export async function sendBroadcastPush(
  title: string,
  body: string,
  targetAudience: 'ALL' | string,
  targetDeepLink: string,
  adminEmail: string
) {
  let query: FirebaseFirestore.Query = adminDb.collection('users');
  if (targetAudience !== 'ALL') {
    query = query.where('interests', 'array-contains', targetAudience);
  }

  const snapshot = await query.get();
  const tokens: string[] = [];

  snapshot.forEach((doc) => {
    const data = doc.data();
    if (data.fcmToken && data.pushNotificationsEnabled !== false) {
      tokens.push(data.fcmToken);
    }
  });

  if (tokens.length === 0) {
    return { success: false, message: 'No registered device tokens found for this audience segment.' };
  }

  const batchSize = 500;
  let successCount = 0;
  let failureCount = 0;

  for (let i = 0; i < tokens.length; i += batchSize) {
    const chunk = tokens.slice(i, i + batchSize);
    const response = await adminMessaging.sendEachForMulticast({
      tokens: chunk,
      notification: { title, body },
      data: {
        click_action: 'FLUTTER_NOTIFICATION_CLICK',
        targetId: targetDeepLink || 'home',
        source: 'CHROMA_BROADCAST',
      },
    });
    successCount += response.successCount;
    failureCount += response.failureCount;
  }

  // Record campaign in Firestore
  const campaignRef = adminDb.collection('broadcast_campaigns').doc();
  await campaignRef.set({
    id: campaignRef.id,
    title,
    body,
    targetAudience,
    deepLinkUrl: targetDeepLink,
    adminEmail,
    totalTokensTargeted: tokens.length,
    successCount,
    failureCount,
    status: 'completed',
    timestamp: Date.now(),
  });

  await logAdminAction(adminEmail, 'SEND_BROADCAST_PUSH', campaignRef.id, {
    title,
    targetAudience,
    successCount,
    failureCount,
  }, 'broadcast');

  revalidatePath('/admin/broadcast');
  return { success: true, sent: successCount, failed: failureCount };
}
```

```typescript
import { adminDb } from '@/lib/firebaseAdmin';

import { revalidatePath } from 'next/cache';

const supabaseAdmin = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_ROLE_KEY!
);

/**
 * Scan Supabase Storage buckets and identify orphaned files unreferenced in Firestore.
 */
export async function scanOrphanedAssetsAction(bucketName: string, adminEmail: string) {
  const { data: files, error } = await supabaseAdmin.storage.from(bucketName).list('', { limit: 1000 });
  if (error || !files) throw new Error(error?.message || 'Failed to list storage bucket');

  const orphanedKeys: string[] = [];
  let totalBytesReclaimable = 0;

  for (const file of files) {
    if (!file.name || file.name.startsWith('.')) continue;

    let isReferenced = false;
    if (bucketName === 'avatars') {
      const snap = await adminDb.collection('users').where('avatarUrl', '>=', file.name).where('avatarUrl', '<=', file.name + '').limit(1).get();
      if (!snap.empty) isReferenced = true;
    } else if (bucketName === 'posts') {
      const snap = await adminDb.collection('community_works').where('imageUrls', 'array-contains-any', [file.name]).limit(1).get();
      if (!snap.empty) isReferenced = true;
    }

    if (!isReferenced) {
      orphanedKeys.push(file.name);
      totalBytesReclaimable += file.metadata?.size || 0;
    }
  }

  await logAdminAction(adminEmail, 'SCAN_ORPHANED_ASSETS', bucketName, {
    totalScanned: files.length,
    orphanedCount: orphanedKeys.length,
    bytesReclaimable: totalBytesReclaimable,
  }, 'storage');

  return { success: true, orphanedKeys, totalBytesReclaimable };
}

 * Purge identified orphaned files from Supabase Storage.
 */
export async function purgeOrphanedAssetsAction(bucketName: string, keys: string[], adminEmail: string) {

  revalidatePath('/admin/storage');
  return { success: true, deletedCount: keys.length };
}
```

```typescript
  for (const userDoc of usersSnap.docs) {
    const uid = userDoc.id;
    const [followersSnap, followingSnap, postsSnap, reelsSnap] = await Promise.all([
      adminDb.collection('users').doc(uid).collection('followers').get(),
      adminDb.collection('users').doc(uid).collection('following').get(),
      adminDb.collection('community_works').where('creatorId', '==', uid).get(),
      adminDb.collection('flash_videos').where('creatorId', '==', uid).get(),
    ]);

    const actualFollowers = followersSnap.size;
    const actualFollowing = followingSnap.size;
    const actualPosts = postsSnap.size;
    const actualReels = reelsSnap.size;

    const data = userDoc.data();
    if (
      data.followersCount !== actualFollowers ||
      data.followingCount !== actualFollowing ||
      data.postsCount !== actualPosts ||
      data.reelsCount !== actualReels
    ) {
      await userDoc.ref.update({
        followersCount: actualFollowers,
        followingCount: actualFollowing,
        postsCount: actualPosts,
        reelsCount: actualReels,
      });
      healedCount++;
    }
  }

  await logAdminAction(adminEmail, 'RECONCILE_COUNTERS', 'GLOBAL', {
    totalScanned: usersSnap.size,
    healedCount,
  }, 'diagnostics');

  return { success: true, totalScanned: usersSnap.size, healedCount };
}

/**
 * Rebuild usernames index.
 */
export async function reindexUsernamesAction(adminEmail: string) {
  const usersSnap = await adminDb.collection('users').get();
  const batch = adminDb.batch();
  let reindexedCount = 0;

  for (const userDoc of usersSnap.docs) {
    const uid = userDoc.id;
    const username = userDoc.data()?.username?.toLowerCase().trim();
    if (username) {
      batch.set(adminDb.collection('usernames').doc(username), {
        uid,
        claimedAt: Date.now(),
        verifiedByReindex: true,
      });
      reindexedCount++;
    }
  }

  await batch.commit();
  await logAdminAction(adminEmail, 'REINDEX_USERNAMES', 'GLOBAL', { reindexedCount }, 'diagnostics');
  return { success: true, reindexedCount };
}
```

1. EXECUTIVE SYSTEM OVERVIEW & ARCHITECTURE
====================================================================================================
ChromaStudio (also branded as Oscellion) is a high-performance creative mobile studio and creator 
social ecosystem built on Android (Kotlin, Jetpack Compose, Material 3, Samsung One UI / Apple Glass 
Design System) connected to a multi-backend cloud architecture:
1. Google Cloud Firebase / Firestore:
   - Primary NoSQL real-time document database.
   - Firebase Authentication (Google OAuth, Apple OAuth, Email/Password, Custom handle logins).
   - Firebase Cloud Messaging (FCM) for low-latency background notifications.
2. Supabase Cloud (PostgreSQL, Storage, Realtime):
   - Media Storage for avatars, banners, post media, and encrypted chat attachments.
   - Realtime websocket subscriptions for presence and telemetry.
3. Cloudinary CDN:
   - High-throughput video transcoding, poster frame extraction, and CDN optimization for Flash reels.
4. Google Gemini GenAI API:
   - Creative AI generative features, prompt expansion, smart captions, and automated content moderation.

The purpose of the Next.js Founder Admin Panel is to provide a single, omniscient web dashboard 
allowing the founder and company operators to:
- Monitor user growth, DAU/MAU, creator retention, and storage consumption in real time.
- Manage user profiles, verify creator accounts with badges, reset compromised sessions, and ban bad actors.
- Review flagged content (posts, reels, stories, comments, chat reports) in a triage queue.
- Broadcast system announcements and push notifications to segmented user demographics.
- Audit the health of cloud storage buckets and prune orphaned media assets.
- Configure feature flags, minimum app version requirements, and platform operational modes.

2.2. Collection: `users`
----------------------------------------------------------------------------------------------------
Path: `users/{uid}`
Document ID: Firebase Authentication UID string (e.g. "aB3dE8fK...")
Purpose: Stores comprehensive user creator profile, account state, badges, privacy settings.

Fields:
- `uid` (string, required): Firebase Auth UID.
- `username` (string, required): Clean lowercase unique handle (3-30 chars, a-z, 0-9, _).
- `displayName` (string, required): Public display name (e.g. "Elena Rostova").
- `email` (string, required): Primary verified email or OAuth email.
- `customEmail` (string, required): Internal handle email format: `{username}@oscellion.com`.
- `googleId` (string, optional): Associated Google OAuth ID.
- `bio` (string, optional): Public profile description (max 500 chars).
- `avatarUrl` (string, optional): HTTPS URL to profile image (Supabase / Cloudinary).
- `bannerUrl` (string, optional): HTTPS URL to profile cover banner.
- `bannerWorkId` (string, optional): ID of a community_work used as profile banner.
- `dob` (number, optional): Date of birth in UTC epoch milliseconds. Enforced 13+.
- `dateOfBirth` (any, optional): Legacy or alternate timestamp format for DOB.
- `gender` (string, default: "Private"): "Male" | "Female" | "Non-binary" | "Private".
- `role` (string, default: "Creator"): "Creator" | "Admin" | "Moderator" | "VIP".
- `verified` (boolean, default: false): True grants the official blue verified badge.
- `online` (boolean, default: false): Live presence indicator.
- `lastSeen` (number, optional): Epoch milliseconds timestamp of last active heartbeat.
- `location` (string, optional): General city/region display.
- `officeLocation` (string, optional): Professional office location.
- `homeLocation` (string, optional): Personal hometown.
- `countryLocation` (string, optional): ISO or full country name.
- `showLocation` (boolean, default: false): Visibility toggle for public location.
- `socialLinks` (map<string, string>): Map of platform key to URL (e.g., {"instagram": "...", "x": "..."}).
- `followersCount` (number, default: 0): Denormalized total followers count.
- `followingCount` (number, default: 0): Denormalized total following count.
- `interests` (array<string>): Array of chosen studio domains (e.g., ["Color Grading", "Motion Graphics"]).
- `statusEmoji` (string, optional): Single emoji status (e.g., "🎨").
- `statusText` (string, optional): Short status message (e.g., "Grading LUTs").
- `agreedToTermsAt` (number, optional): Epoch milliseconds when terms were accepted.
- `createdAt` (number / timestamp): Account creation timestamp.
- `isOnboarded` (boolean, default: true): Whether onboarding wizard was completed.
- `publicKey` (string, optional): Base64 encoded RSA-2048 public key for E2EE chats.
- `isPrivateAccount` (boolean, default: false): If true, requires follow requests to view posts.
- `allowTagging` (boolean, default: true): Whether others can tag/mention this user.
- `showOnlineStatus` (boolean, default: true): Whether online status dot is visible to others.
- `pushNotificationsEnabled` (boolean, default: true): Master push notification toggle.
- `emailNotificationsEnabled` (boolean, default: true): Email updates toggle.
- `quietModeEnabled` (boolean, default: false): Do not disturb / silent mode toggle.
- `unrecognizedLoginsEnabled` (boolean, default: false): Security alert on unknown device login.
- `contentTags` (array<string>): Creator tags applied to user's profile.
- `dataVisibility` (map<string, string>): Granular privacy settings.
- `onlyFriends` (array<string>): UIDs of close friends allowed in restricted stories.
- `fcmToken` (string, optional): Active device FCM registration token.
- `blockedUsers` (array<string>): UIDs blocked by this user.
- `isBanned` (boolean, default: false, ADMIN-MANAGED): If true, user is locked out.
- `banReason` (string, optional, ADMIN-MANAGED): Administrative explanation for ban.
- `bannedAt` (number, optional, ADMIN-MANAGED): Timestamp when ban was enacted.

- `title` (string): Post headline.
- `description` (string): Caption / description text.
- `aspectRatio` (string, default: "4:3"): "1:1" | "4:3" | "9:16" | "16:9".
- `postType` (string, default: "work"): "work" (interactive JSON gradient) | "image" (photo) | "video".
- `imageUrl` (string, optional): Primary media image URL.
- `imageUrls` (array<string>): Array of media image URLs for multi-slide carousel posts.
- `videoUrl` (string, optional): Video playback URL if postType == "video".
- `thumbnailUrl` (string, optional): Poster frame image URL for video posts.
- `jsonUrl` (string, optional): Cloud storage URL to the JSON gradient layers file.
- `workUrls` (array<string>): Associated project resource URLs.
- `likesCount` (number, default: 0): Denormalized likes counter.
- `likedBy` (array<string>): Array of UIDs who liked (truncated for performance).
- `remixCount` (number, default: 0): Number of times other creators remixed this canvas.
- `remixedBy` (array<string>): Array of remixed user UIDs.
- `downloadCount` (number, default: 0): Total downloads.
- `downloadedBy` (array<string>): UIDs who downloaded.
- `shareCount` (number, default: 0): Total shares.
- `sharedBy` (array<string>): UIDs who shared.
- `saveCount` (number, default: 0): Total saves / bookmarks.
- `savedBy` (array<string>): UIDs who bookmarked.
- `commentsCount` (number, default: 0): Total top-level + reply comments.
- `commentCount` (number, default: 0): Duplicate counter field maintained for backward compatibility.
- `tags` (array<string>): Hashtags and category tags (e.g. ["#LUT", "#FilmGrain"]).
- `mentions` (array<string>): Tagged usernames.
- `trendingTag` (string, optional): Elevated badge (e.g., "Trending", "Staff Pick").
- `timestamp` (number): Epoch milliseconds when posted.
- `hideLikesCount` (boolean, default: false): Creator privacy toggle hiding like count from public.
- `hideSharesCount` (boolean, default: false): Hides share count.
- `hideRemixesCount` (boolean, default: false): Hides remix counter.
- `hideDownloadsCount` (boolean, default: false): Hides download counter.
- `hideSavesCount` (boolean, default: false): Hides bookmark count.
- `turnOffComments` (boolean, default: false): Disables new comments.
- `turnOffRemix` (boolean, default: false): Prevents remixing in Studio.
- `remixedFromPostId` (string, optional): Parent post ID if this post was remixed.
- `remixedFromAuthorId` (string, optional): Parent author UID.
- `remixedFromAuthorUsername` (string, optional): Parent author handle.
- `remixedFromAuthorDisplayName` (string, optional): Parent author name.
- `remixedFromAuthorAvatar` (string, optional): Parent author avatar.
- `remixedFromAuthorVerified` (boolean, default: false): Parent author verification.
- `archived` (boolean, default: false): If true, hidden from public feed but kept in creator archive.
- `isFeatured` (boolean, default: false, ADMIN-MANAGED): Featured on explore carousel.
- `isTakedown` (boolean, default: false, ADMIN-MANAGED): Removed by moderation for violations.
- `takedownReason` (string, optional, ADMIN-MANAGED): Why moderation removed the post.

- `pinnedMessageText` (string, optional): Text of pinned message.
- `pinnedBy` (string, optional): UID who pinned.
- `pinnedAt` (number, optional): Timestamp when pinned.
- `onlyAdminsCanPost` (boolean, default: false): Group restriction setting.

----------------------------------------------------------------------------------------------------
2.16. Subcollection: `chats/{roomId}/messages`
----------------------------------------------------------------------------------------------------
Path: `chats/{roomId}/messages/{messageId}`
Document ID: `messageId` (UUID string)
Purpose: Individual chat messages, voice notes, media attachments, and polls.
NOTE: In E2EE mode, the `text` field contains cipher bytes and can only be decrypted by 
the participants holding the private key. Admin panel inspects metadata, not private plaintext.

Fields:
- `id` (string): Message ID.
- `senderId` (string): UID of author.
- `text` (string): Message body (Plaintext or AES-GCM Ciphertext).
- `timestamp` (number): Epoch milliseconds sent.
- `isRead` (boolean, default: false): Read receipt state.
- `isDelivered` (boolean, default: false): Delivery receipt state.
- `imageUrl` (string, optional): Image attachment URL.
- `mediaUrl` (string, optional): Voice note audio URL or video URL.
- `mediaType` (string, optional): MIME type (e.g. "audio/mp4", "video/mp4", "image/jpeg").
- `workId` (string, optional): Attached Chroma Studio project work ID.
- `messageType` (string, default: "text"): "text" | "image" | "video" | "audio" | "system" | 
                                          "poll" | "story_reply" | "flash_share" | "call".
- `iv` (string, optional): Base64 initialization vector for AES-GCM.
- `encryptedAesKeys` (map<string, string>): Map of `participantId -> RSA-encrypted AES key`.
- `reactions` (map<string, string>): Map of `userId -> emoji` (e.g. {"uid1": "❤️", "uid2": "🔥"}).
- `durationSeconds` (number, optional): Duration in seconds for voice notes.
- `replyToMessageId` (string, optional): Parent message ID being replied to.
- `pollVotes` (map<string, string>): Map of `userId -> selected option index`.
- `isEdited` (boolean, default: false): True if message was modified after sending.
- `deletedFor` (array<string>): UIDs who deleted this message for themselves.
- `isPollClosed` (boolean, default: false): Whether poll voting has concluded.
- `isForwarded` (boolean, default: false): True if forwarded from another chat.
- `storyId`, `storyThumbnailUrl`: Story reply attachments.
- `flashVideoId`, `flashVideoThumbnailUrl`, `flashVideoUrl`, `flashVideoCaption`: Flash reel attachments.
- `callDuration`, `callType`: Call history records ("voice" | "video").

----------------------------------------------------------------------------------------------------
2.17. Collection: `user_chat_prefs`
----------------------------------------------------------------------------------------------------
Path: `user_chat_prefs/{userId}_{roomId}`
Document ID: Composite key `{userId}_{roomId}`
Fields:
- `wallpaperUri` (string, optional): Custom chat background image.
- `muted` (boolean, default: false): Mute notifications for this room.
- `customNotificationSound` (string, optional): Notification tone override.

----------------------------------------------------------------------------------------------------
2.18. Collection: `reports`
----------------------------------------------------------------------------------------------------
Path: `reports/{reportId}`
Document ID: `reportId` (UUID string)
Purpose: Centralized trust, safety, moderation, and abuse triage queue.

Fields:
- `id` (string): Report ID.
- `reporterId` (string): UID of the user filing the report.
- `reporterUsername` (string): Handle of reporter.
- `targetType` (string): "user" | "post" | "flash" | "story" | "comment" | "chat_message".
- `targetId` (string): Document ID of the offending entity.
- `targetAuthorId` (string): UID of the accused author.
- `targetAuthorUsername` (string): Handle of the accused author.
- `reason` (string): "Spam" | "Harassment or Hate Speech" | "Nudity or Sexual Content" | 
                    "Violence or Dangerous Organizations" | "Copyright Infringement" | "Other".
- `description` (string, optional): Detailed explanation from reporter.
- `evidenceUrl` (string, optional): Screenshot or media link.
- `status` (string, default: "pending"): "pending" | "investigating" | "resolved" | "dismissed".
- `resolutionAction` (string, optional): "none" | "warned_user" | "content_removed" | 
                                         "account_suspended_24h" | "account_banned_permanent".
- `resolvedBy` (string, optional): Admin UID or email of the resolving operator.
- `resolvedAt` (number, optional): Epoch milliseconds when resolved.
- `createdAt` (number): Epoch milliseconds filed.

4.3. Role-Based Access Control (RBAC) Matrix
--------------------------------------------
Implement custom claims on Firebase Auth (`adminRole`) or manage in `admin_users` collection:
- `FOUNDER_SUPERADMIN`: Full read/write/delete access across all 12 modules, financial metrics, 
  permanent user deletion, and direct database execution.
- `MODERATOR`: Access to Moderation Queue, Posts, Flash, Comments, and Stories. Can take down content, 
  issue user warnings, and enact 24h suspensions. Cannot permanently delete users.
- `SUPPORT_AGENT`: Access to User Management, Device Tokens, and Chat Metadata. Can trigger password 
  resets and view user account status. Cannot delete content or view admin logs.
- `CONTENT_CURATOR`: Access to Community Works, Featured Carousels, and Broadcast Notifications. 
  Can feature posts and create announcements.

```typescript
/**
 * Ban user account and revoke all authentication tokens.
 */
export async function banUser(uid: string, reason: string, adminEmail: string) {
  // 1. Mark banned in Firestore profile
  await adminDb.collection('users').document(uid).update({
    isBanned: true,
    banReason: reason,
    bannedAt: Date.now(),
  });

  // 2. Revoke Firebase Auth tokens immediately
  await adminAuth.revokeRefreshTokens(uid);

  // 3. Log administrative audit trail
  await logAdminAction(adminEmail, 'BAN_USER', uid, { reason });
  revalidatePath(`/admin/users/${uid}`);
  return { success: true };
}

/**
 * Unban user account.
 */
export async function unbanUser(uid: string, adminEmail: string) {
  await adminDb.collection('users').document(uid).update({
    isBanned: false,
    banReason: null,
    bannedAt: null,
  });
  await logAdminAction(adminEmail, 'UNBAN_USER', uid, {});
```

7.3. Moderation Server Actions (`actions/moderation.ts`)
--------------------------------------------------------
```typescript
'use server';

import { adminDb } from '@/lib/firebaseAdmin';
import { logAdminAction } from '@/lib/auditLogger';
import { banUser } from './users';
import { revalidatePath } from 'next/cache';

export async function resolveReport(
  reportId: string,
  action: 'none' | 'warned' | 'content_removed' | 'suspended_24h' | 'banned_permanent',
  adminEmail: string
) {
  const reportRef = adminDb.collection('reports').doc(reportId);
  const reportSnap = await reportRef.get();
  if (!reportSnap.exists) throw new Error('Report not found');

  const report = reportSnap.data()!;

  // Execute resolution action
  if (action === 'content_removed') {
    if (report.targetType === 'post') {
      await adminDb.collection('community_works').doc(report.targetId).update({
        isTakedown: true,
        takedownReason: `Violated terms: ${report.reason}`,
      });
    } else if (report.targetType === 'flash') {
      await adminDb.collection('flash_videos').doc(report.targetId).update({
        isTakedown: true,
      });
    } else if (report.targetType === 'comment') {
      await adminDb.collection('flash_comments').doc(report.targetId).delete();
    }
  } else if (action === 'banned_permanent') {
    await banUser(report.targetAuthorId, `Banned via Report: ${report.reason}`, adminEmail);
  }

  // Update report state
  await reportRef.update({
    status: 'resolved',
    resolutionAction: action,
    resolvedBy: adminEmail,
    resolvedAt: Date.now(),
  });

  await logAdminAction(adminEmail, 'RESOLVE_REPORT', reportId, { action, targetId: report.targetId });
  revalidatePath('/admin/moderation');
  return { success: true };
}
```

7.4. Broadcast Notification Server Action (`actions/broadcast.ts`)
------------------------------------------------------------------
```typescript
'use server';

import { adminDb, adminMessaging } from '@/lib/firebaseAdmin';
import { logAdminAction } from '@/lib/auditLogger';

export async function sendBroadcastPush(
  title: string,
  body: string,
  targetAudience: 'ALL' | string, // 'ALL' or specific interest domain e.g. "Color Grading"
  targetDeepLink: string,
  adminEmail: string
) {
  // Query users collection for device tokens
  let query: FirebaseFirestore.Query = adminDb.collection('users');
  if (targetAudience !== 'ALL') {
    query = query.where('interests', 'array-contains', targetAudience);
  }

  const snapshot = await query.get();
  const tokens: string[] = [];

  snapshot.forEach((doc) => {
    const data = doc.data();
    if (data.fcmToken && data.pushNotificationsEnabled !== false) {
      tokens.push(data.fcmToken);
    }
  });

  if (tokens.length === 0) {
    return { success: false, message: 'No registered device tokens found for this segment.' };
  }

  // FCM multicast chunking (max 500 per batch)
  const batchSize = 500;
  let successCount = 0;
  let failureCount = 0;

  for (let i = 0; i < tokens.length; i += batchSize) {
    const chunk = tokens.slice(i, i + batchSize);
    const response = await adminMessaging.sendEachForMulticast({
      tokens: chunk,
      notification: { title, body },
      data: {
        click_action: 'FLUTTER_NOTIFICATION_CLICK',
        targetId: targetDeepLink,
        source: 'CHROMA_BROADCAST',
      },
    });
    successCount += response.successCount;
    failureCount += response.failureCount;
  }

  await logAdminAction(adminEmail, 'SEND_BROADCAST', 'GLOBAL', {
    title,
    targetAudience,
    successCount,
    failureCount,
  });

  return { success: true, sent: successCount, failed: failureCount };
}
```
